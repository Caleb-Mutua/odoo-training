# Odoo Training – Real Estate Module

This repository contains an **Odoo 18 Real Estate module** built as part of my technical training.

## Features Implemented
- Property management
- Property types
- Property tags
- Property offers
- Sales information (buyer & salesperson)

## Tech Stack
- Odoo 18
- Python
- XML

## What I Learned
- Creating custom Odoo models and views
- Working with relational fields (Many2one, One2many, Many2many)
- Managing access rights and security rules
- Debugging XML and Python issues using Odoo logs
- Understanding differences between Odoo versions

## Challenges Faced
- View crashes due to XML structure errors
- Access rights issues from `ir.model.access.csv`
- Handling One2many lines in list views
- Aligning UI behavior with Odoo 18 expectations

## Status
🚧 Training project – continuously improving.
